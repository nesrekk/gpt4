🩺🤖 Built an AI-Powered Medical Symptom Assistant, with safety first!

For my 24CS2506 – Building Applications using GPT-4 lab, I built a symptom assistant that runs locally with Ollama and gives structured, cautious health information.

How it works:
1️⃣ Collects age, sex, symptoms, duration, severity, history, medication and allergies
2️⃣ Extracts the individual symptoms with the LLM
3️⃣ A rule-based safety module checks for emergency red flags (chest pain, breathing difficulty, stroke signs …) and assigns a triage level, without relying on the LLM
4️⃣ Lists possible conditions with likelihood and reasoning, self-care tips and when to see a doctor
5️⃣ Asks follow-up questions and refines the analysis using the answers
6️⃣ Saves every report as .txt and .json

Every report states clearly that it is NOT a medical diagnosis.

Tech: Python • Ollama (Llama 3.2, JSON mode) • Prompt Engineering • Rule-based triage
